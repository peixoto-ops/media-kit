# AutoEQ Preset for JBL Endurance Race 2
# Base: Harman IEM Target 2019v2
# Ajuste: compensação para design aberto (earhook, sem selo)
# O JBL Endurance Race 2 não possui medição específica nos bancos
# AutoEQ (oratory1990/Crinacle/Squiglink). Esta curva foi gerada
# a partir das características conhecidas do fone:
#   - Driver 8mm dinâmico
#   - Design aberto (earhook) → perda de sub-graves abaixo de 100Hz
#   - Assinatura JBL: V-shape suave com presença marcante
#
# Pré-requisito: adicionar "Equalizador Gráfico" (GraphicEQ) 
# como efeito no EasyEffects (lado Output) e importar este arquivo.
#
# Fonte da metodologia: https://github.com/jaakkopasanen/AutoEq
